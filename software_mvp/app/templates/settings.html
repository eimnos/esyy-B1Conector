Attivazione BigQuery in Google Cloud (obbligatoria)
Da completare prima della configurazione BigQuery in app.
  1. Apri https://console.cloud.google.com e seleziona il progetto cliente corretto.
  2. Menu principale -> Billing -> collega un account di fatturazione attivo.
  3. Menu -> APIs & Services -> Library -> cerca BigQuery API -> Enable.
  4. Menu -> IAM & Admin -> Service Accounts -> Create Service Account.
  5. Nome consigliato: esyy-b1connector-prod (o naming cliente).
  6. Assegna ruoli: BigQuery Job User + BigQuery Data Editor.
  7. Apri il service account -> tab Keys -> Add Key -> Create new key -> JSON.
  8. Salva il file JSON sul server app (es. C:\BigQuery\chiave_cliente.json).
  9. Apri BigQuery Studio e verifica che il progetto sia visibile.
